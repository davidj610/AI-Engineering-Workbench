# 03 -- Prompt Library

> **Purpose**
>
> This directory contains curated prompt collections organized by
> **engineering task** rather than by AI product.

## Why organize by task?

AI tooling evolves rapidly. A prompt that works well today in Codex CLI
may work equally well tomorrow in an IDE agent or ChatGPT. The enduring
concept is the engineering task.
