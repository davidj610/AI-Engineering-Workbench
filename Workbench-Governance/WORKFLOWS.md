# WORKFLOWS.md

## Publish Chapter

Trigger:

> Publish the attached chapter.

Workflow:

1.  Place chapter in the correct directory.
2.  Preserve formatting.
3.  Update README if necessary.
4.  Stage changes.
5.  Commit.
6.  Push.
7.  Summarize results.

------------------------------------------------------------------------

## Create New Chapter

Trigger:

> Create a new chapter.

Workflow:

1.  Follow STYLE_GUIDE.md.
2.  Create Markdown.
3.  Link related chapters.
4.  Commit and push.

------------------------------------------------------------------------
