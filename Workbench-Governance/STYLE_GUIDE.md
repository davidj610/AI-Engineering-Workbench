# STYLE_GUIDE.md

## Goal

Every chapter should read like a professional engineering handbook.

## Standard Structure

1.  Purpose
2.  Key Takeaways
3.  Overview
4.  Concepts
5.  Architecture
6.  Practical Examples
7.  Engineering Workflows
8.  Best Practices
9.  Common Pitfalls
10. Lessons Learned
11. Related Chapters

## Writing Style

-   Prefer clear English over jargon.
-   Explain *why*, not only *how*.
-   Be concise but complete.
-   Include real-world examples.
-   Explain tradeoffs.
-   Use active voice.

## Markdown

-   Use fenced code blocks.
-   Use Mermaid for diagrams.
-   Keep headings consistent.
-   Use tables where appropriate.
