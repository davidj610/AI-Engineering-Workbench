# AGENTS.md

> Repository instructions for AI agents (Codex, future IDE agents, and
> other automation).

## Mission

Maintain this repository as a high-quality engineering reference. Favor
clarity, consistency, and correctness over speed.

## Publishing Workflow

When asked to **publish** a chapter:

1.  Determine the correct destination.
2.  Preserve Markdown formatting.
3.  Update `README.md` if navigation changes.
4.  Update any table of contents if present.
5.  Preserve existing links.
6.  Do **not** rewrite content unless requested.
7.  Stage all modified files.
8.  Create a concise commit message.
9.  Push to the current remote.
10. Summarize the changes made.

## Editing Rules

-   Preserve author's writing style.
-   Do not reorder sections unless requested.
-   Keep fenced code blocks intact.
-   Prefer Mermaid for diagrams.
-   Use relative links.

## Commit Messages

Examples:

-   Add Prompt Library chapter
-   Expand PostgreSQL prompts
-   Refine MCP documentation
-   Add AI workflow examples
